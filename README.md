# Greenwood Public Library 📚

A modern, highly responsive, and beautifully styled web landing page designed for a community public library. Built with a clean minimalist aesthetic, smooth typography, and interactive components to provide visitors with an engaging browsing experience.

---

## 🌟 Project Overview

The Greenwood Public Library web application serves as a digital gateway for patrons, offering a comprehensive look into the library's physical spaces, membership structures, upcoming events, and community resources. The layout features a polished design using a contemporary utility-first CSS framework and lightweight JavaScript enhancements.

---

## ✨ Key Features & Sections

- **Navigation Bar & Sticky Header:** 
  - Features quick-access links to core sections including Sections, Gallery, Membership, and Events.
  - Includes an operating status badge ("Open Sat") and a direct contact layout.
- **Visual Library Gallery:** 
  - Showcases key library zones such as Reading Rooms, Children's Corner, and Digital Labs.
  - Features an interactive **"View All" / "Show Less" toggle script** to dynamically expand or collapse additional photo grids.
- **Membership Tier Cards:** 
  - Outlines distinct subscription models including **Basic (Free)**, **Student (₹200/yr)**, and **Family (₹500/yr)** with highlighted popular tiers and clear call-to-action buttons.
- **Events & Workshops Grid:** 
  - Highlights upcoming community gatherings like the Summer Reading Challenge, Book Club reviews, Digital Literacy workshops, and Author Meet-and-Greets.
  - Enhanced with smooth hover-to-underline animations and image scaling effects.
- **Community Testimonial:** 
  - Features a dedicated quote section highlighting local volunteer experiences.
- **Footer & Contact Box:** 
  - Provides a distinct contact card with library location details (42 Elm Street), operating hours, direct phone links, and social media handles.

---

## 🛠️ Tech Stack & Tools

- **Markup:** HTML5 (Semantic structure and layout design)
- **Styling:** Tailwind CSS (Loaded via CDN for rapid, responsive UI composition and custom spacing/transitions)
- **Interactivity:** Vanilla JavaScript (DOM manipulation for gallery state toggling)
- **Asset Management:** Unsplash (High-resolution placeholder photography)
- **Development Environment:** Visual Studio Code on Windows with local live-server deployment

---

## 🚀 Getting Started & Local Setup

To run or inspect this project locally on your system:

1. **Clone or Download:** 
   Clone this repository or download the project folder containing your `index.html` file.
2. **Open in IDE:** 
   Open the project folder inside **Visual Studio Code**.
3. **Run Live Server:** 
   Right-click `index.html` and select **"Open with Live Server"** (or use the VS Code Live Server extension) to view it live in your browser at `http://127.0.0.1:5500`.
